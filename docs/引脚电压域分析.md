# 扩展引脚电压域实测分析：为什么只有 GPIO3_B6 能点亮 LED

> 现象：Pin32(GPIO3_B6) 亮度正常，Pin36(GPIO1_D0) 很暗，Pin38(GPIO1_D4) 完全不亮。
> 已排除接线与导线问题。
>
> 结论：**三个脚不在同一个 IO 电压域**——这是硬件设计决定的，与软件配置无关。

---

## 一、软件侧先排除

三个脚的 pinctrl 配置完全一致：

```
pin 56  (gpio1-24, GPIO1_D0): (MUX UNCLAIMED) gpio1:56
pin 60  (gpio1-28, GPIO1_D4): (MUX UNCLAIMED) gpio1:60
pin 110 (gpio3-14, GPIO3_B6): (MUX UNCLAIMED) gpio3:110
```

`pinconf-pins` 显示驱动能力也一样：

| 引脚 | 驱动强度 | 上下拉 | 输出电平 |
| --- | --- | --- | --- |
| GPIO1_D0 (pin 56) | 12 mA | pull-down | 0 |
| GPIO1_D4 (pin 60) | 12 mA | pull-up | 0 |
| GPIO3_B6 (pin 110) | 12 mA | pull-down | 0 |

→ **不是驱动能力差异，也不是 MUX 差异。**

---

## 二、真正的差异：VCCIO 电压域

从原理图 `k1_mini_v2.2.pdf` 提取（`pdftotext -layout` + 检索）：

```
VCCIO2 Domain
Operating Voltage=1.8V/3.3V
    EMMC_D0      / FLASH_D0    / GPIO1_B4_u
    ...
    EMMC_RSTn    / FSPI_D2     / FLASH_WPn / GPIO1_C7_d
    FSPI_CLK     / FLASH_ALE   / GPIO1_D0_d     ← Pin36
    FSPI_D3      / FLASH_CS1n  / GPIO1_D4_u     ← Pin38

Default is determined by Pin
FLASH_VOL_SEL/GPIO0_A7_u:
L: VCCIO2 must supply 3.3V
H: VCCIO2 must supply 1.8V
供电：VCCIO_FLASH
```

而 GPIO3_B6 在另一个域：

```
VCCIO5 Domain
    ... GPIO3_B5, GPIO3_B6 ...
供电：VCC_3V3
```

### 结论表

| 40Pin | GPIO | 所属电压域 | 供电轨 | 实际电压 | 点亮 3.3V LED |
| --- | --- | --- | --- | --- | --- |
| **Pin32** | GPIO3_B6 | VCCIO5 | VCC_3V3 | **3.3 V** | ✅ 正常 |
| **Pin36** | GPIO1_D0 | **VCCIO2** | VCCIO_FLASH | **1.8 V** | ❌ 很暗 |
| **Pin38** | GPIO1_D4 | **VCCIO2** | VCCIO_FLASH | **1.8 V** | ❌ 不亮 |

**为什么 1.8V 点不亮 3.3V 的 LED：**

普通红/绿 LED 的正向压降 Vf ≈ 1.8~2.1V。
- 3.3V 供电：`(3.3 - 2.0) / 220Ω ≈ 5.9 mA` → 正常可见
- 1.8V 供电：`1.8 - 2.0 < 0` → **不导通**，或只有极小的漏电流 → 很暗/不亮

Pin36 之所以"很暗"而不是"全灭"，是因为那颗 LED 的 Vf 恰好略低于 1.8V，
勉强有几百微安流过。

---

## 三、还有一层：这两个脚挂着额外电路

原理图 40Pin 区域还显示 GPIO1_D0 / GPIO1_D4 各接了一路 **2SK3018 电平转换电路**：

```
GPIO1_D0 ──R9129(10K)── Q9100(2SK3018) ── 输出侧
GPIO1_D4 ──R9132(10K)── Q9101(2SK3018) ── 输出侧
                          配 R9130 / R9133 (2.2K)
```

这两个 MOS 管把 1.8V 信号转换给 3.3V 侧的网络（调试串口相关）。
**所以 Pin36/Pin38 不是"干净的 GPIO 输出"**，它们挂着一个电平转换负载，
即使用电平转换器放大，输出阻抗也不理想。

→ 这两个脚**本来就不是为"直接驱动外部负载"设计的**。

---

## 四、解决办法

### ✅ 方案 1：换到 3.3V 域的引脚（推荐，零硬件成本）

板上 10 个 LED 节点分属不同域：

| LED 节点 | 40Pin | 电压域 | 供电轨 | 电压 | 可驱动 LED |
| --- | --- | --- | --- | --- | --- |
| gpio3b5 | Pin29 | VCCIO5 | VCC_3V3 | 3.3 V | ✅ |
| gpio3b6 | Pin32 | VCCIO5 | VCC_3V3 | 3.3 V | ✅ |
| gpio4c4 | Pin27 | VCCIO7 | VCC_3V3 | 3.3 V | ✅ |
| gpio4c6 | Pin25 | VCCIO7 | VCC_3V3 | 3.3 V | ✅ |
| gpio1a4 | Pin7 | VCCIO1 | VCCIO_ACODEC | 3.0 V | ✅ |
| gpio1b0 | Pin11 | VCCIO1 | VCCIO_ACODEC | 3.0 V | ✅ |
| gpio1b1 | Pin13 | VCCIO1 | VCCIO_ACODEC | 3.0 V | ✅ |
| gpio1b2 | Pin15 | VCCIO1 | VCCIO_ACODEC | 3.0 V | ✅ |
| **gpio1d0** | **Pin36** | **VCCIO2** | VCCIO_FLASH | **1.8 V** | ❌ |
| **gpio1d4** | **Pin38** | **VCCIO2** | VCCIO_FLASH | **1.8 V** | ❌ |

**8 个可用，够用。**

建议新映射（`config.json` 里改一下即可）：

```json
"gesture_to_led": {
  "rock":     "gpio4c4",
  "paper":    "gpio4c6",
  "scissors": "gpio3b6"
}
```

### 方案 2：非要留在 Pin36/Pin38 —— 加一级驱动

1.8V 逻辑电平驱动 MOS 管/三极管是完全可行的：

```
Pin36/38 ──1K──┤ NPN (S8050) 基极
               │ 发射极 ── GND
               │ 集电极 ── LED 阴极
                          LED 阳极 ── 220Ω ── 3.3V(或5V)
```
或 MOS 版本：`2N7002`（Vgs(th) 典型 1.5V，1.8V 勉强）、
**`BSS138` 更稳（Vgs(th) 0.8~1.5V）**。

注意：LED 要用**外部电源 + 共地**，不要指望引脚本身供电。

### ❌ 方案 3：把 VCCIO2 改成 3.3V —— 绝对不行

`VCCIO2` 由 `VCCIO_FLASH` 供电，同时供给 **eMMC 的 I/O**。
eMMC 是 1.8V 接口，改成 3.3V 会**烧掉 eMMC**，板子直接变砖。

## 五、自己验证的方法

### 方法 A：万用表（最直接）

```bash
# 让三个脚同时输出高
for l in gpio3b6 gpio1d0 gpio1d4; do echo 1 | sudo tee /sys/class/leds/$l/brightness; done
```

用万用表直流电压档，黑表笔接 GND（Pin6/9/14/20/30/34/39），红表笔依次测：

| 测量点 | 预期 |
| --- | --- |
| Pin32 对 GND | ≈ **3.3 V** |
| Pin36 对 GND | ≈ **1.8 V** |
| Pin38 对 GND | ≈ **1.8 V** |

测完记得关掉：
```bash
for l in gpio3b6 gpio1d0 gpio1d4; do echo 0 | sudo tee /sys/class/leds/$l/brightness; done
```

### 方法 B：没有万用表时

用一颗**红色 LED + 220Ω** 分别接三个脚试：
- 3.3V 脚：正常亮度
- 1.8V 脚：不亮或极暗

这与你的现象一致，已经算验证过了。

---

## 六、经验总结

1. **"GPIO 能用" ≠ "能驱动负载"**。电压域、驱动能力、外部挂载电路，三者都影响最终能不能点亮一个 LED。
2. RK3568 有 7 个 VCCIO 域，**同一块板上不同引脚电压可以不一样**。选引脚前必须查原理图。
3. 特别要避开和 **eMMC / Flash / ADC / Codec** 共享电压域的引脚——它们通常不是 3.3V。
4. 用万用表量一次电压，比调试半天软件有效得多。

## 附：这次用到的命令

```bash
# 板上查 pinconf
sudo cat /sys/kernel/debug/pinctrl/pinctrl-rockchip-pinctrl/pinconf-pins | grep -E "^pin (56|60|110) "

# 板上查所有 regulator 电压
for r in /sys/class/regulator/*/; do
    n=$(cat $r/name 2>/dev/null); v=$(cat $r/microvolts 2>/dev/null)
    [ -n "$v" ] && printf "%-32s %6s mV\n" "$n" $((v/1000))
done | sort

# 原理图转文本后检索
sudo apt install -y poppler-utils
pdftotext -layout k1_mini_v2.2.pdf sch.txt
grep -n "VCCIO2 Domain" sch.txt
grep -n "GPIO1_D0\|GPIO1_D4\|GPIO3_B6" sch.txt | head
```
